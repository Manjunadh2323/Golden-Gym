# Golden Gym V4.1 update notes

This update is based on the supplied Golden_Gym_V4.0_Corrected archive. Existing payment gateway integrations, member workflows, attendance, refunds, workout and fitness features were retained.

## Added
- Owner inventory register with low-stock/reorder indicator.
- Expense recording and expense history.
- Staff directory for contact/role records (separate from login permissions).
- Printable member ID card page.
- Owner navigation links to the new modules.

## Payment journey retained
- Public membership plans retain the `Join & Pay Online` action.
- Registration creates a pending payment.
- Cashfree hosted checkout remains the preferred configured gateway.
- Razorpay remains the fallback when Cashfree credentials are not configured.
- Membership activation remains dependent on server-side payment verification.

## Apply update
1. Back up your existing project and database.
2. Extract this folder.
3. Create/activate a fresh virtual environment and install `requirements.txt`.
4. Configure `.env` using `.env.example`; never use real credentials in source control.
5. Run `python manage.py migrate`.
6. Run `python manage.py check`.
7. Run locally and test sandbox payment before production use.

## Important
The staff directory stores staff records; it does not provision staff login accounts or permissions. Payment gateways require valid merchant credentials and HTTPS for production webhooks. This package has not been connected to your merchant accounts or live-tested with real payments.
