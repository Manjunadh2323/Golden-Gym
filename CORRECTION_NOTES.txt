GOLDEN GYM V4.0 - CORRECTED PACKAGE

This package uses the newer V4.0 application code, including the RefundRequest
model, migration 0008, member refund request flow, and owner refund management.

Membership plans are stored in db_v21.sqlite3. The SQLite default in
goldengym/settings.py now points to db_v21.sqlite3 when DB_NAME is not set.
The included .env.example also specifies DB_NAME=db_v21.sqlite3.

SETUP:
1. Extract this folder.
2. Optionally copy .env.example to .env and add your regenerated Cashfree Sandbox
   credentials. Do not reuse credentials previously shared in chat or an old .env.
3. Activate your virtual environment and install requirements.
4. Run: python manage.py check
5. Run: python manage.py migrate
6. Run: python manage.py runserver 8002

The migrate command applies migration 0008_refund_requests to the populated
database while retaining its existing membership plans and gym records.

The actual .env file is intentionally not included to protect API credentials.
