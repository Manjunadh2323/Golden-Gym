# Golden Gym V4.0 — Remote Membership Payments (implementation build)

This separate V4.0 folder is based on the uploaded V3.0 project. The original V3.0 ZIP is not modified.

## Added in this build
- Cashfree Hosted Checkout for public membership registration and member renewals.
- Checkout can be opened by members using the public HTTPS website from outside the gym.
- Public Cashfree checkout requires a valid 10-digit phone number (Cashfree's customer-details requirement); offline/manual member creation can still use no phone.
- Server-side order creation and payment-status fetch after return.
- Cashfree webhook signature validation, followed by server-to-server payment status confirmation.
- Membership activation only after a successful payment is confirmed by Cashfree.
- Idempotent activation to avoid duplicate membership periods.
- Existing Razorpay flow remains available as fallback when Cashfree credentials are not configured.
- Existing V3.0 code, migrations, database schema and features are retained; only a new migration adds Cashfree order/session fields.

## Configure Cashfree Sandbox
Add these to `.env` (never commit real secrets):
```
CASHFREE_APP_ID=your_sandbox_app_id
CASHFREE_SECRET_KEY=your_sandbox_secret_key
CASHFREE_ENV=sandbox
CASHFREE_API_VERSION=2023-08-01
```
Use your Cashfree merchant dashboard's Sandbox credentials. To receive webhooks in production, the deployed site must use HTTPS and the webhook URL must be configured/allowed in Cashfree.

## Run locally
```
py -m venv venv
.env\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
# Add Sandbox credentials to .env
python manage.py check
python manage.py migrate
python manage.py runserver 8002
```
For a local webhook test, use a secure tunnel that forwards to your local server and configure the resulting HTTPS webhook URL in Cashfree Sandbox.

## Before real payments
- Complete Cashfree merchant onboarding and KYC.
- Configure production App ID/Secret only in the hosting provider's secret manager.
- Set `CASHFREE_ENV=production`, use HTTPS, set secure `SECRET_KEY`, `DEBUG=False`, `ALLOWED_HOSTS`, CSRF trusted origins and production database.
- Configure and verify Cashfree webhook delivery.
- Run sandbox tests for success, failure, dropped checkout, delayed payment, duplicate webhook, amount mismatch and renewal.
- Test live with a small authorized transaction after merchant approval.
- This build has not been live-tested against the user's Cashfree account; credentials and merchant approval are not available in this environment.

## Scope note
This build adds the requested remote membership registration/payment and remote renewal workflow. It is not yet the complete all-features V4.0 roadmap (inventory, expenses, diet plans, advanced staff management, etc. remain separate work).
